## Decisions made (and why)
- **ADR-0018 promoted (build-time amendment, user-gated).** The EVAL per-technique ship gate ("≥3 puzzles requiring EACH technique as the exact hardest step") proved partly infeasible: across ~4,500 graded puzzles, **zero** had jellyfish as the exact hardest (it is never a unique bottleneck in a constructive ladder — the diminishing-returns reality ADR-0002/domain-research X2 anticipated). ADR-0018 splits the gate: **isolable** techniques (11/12) keep the strict floor+ceiling exact-hardest gate; **un-isolable** (jellyfish only) require a fixture where the technique **fires + every elimination is replay-sound**. The no-backtracking/soundness guarantee (AC-2 replay) applies UNIFORMLY to all 35 fixtures of both tiers — only the isolation clause is relaxed. See DESIGN_DECISIONS.md ADR-0018.
- Candidate model = `basicCandidates(board) &^ eliminations`, rebuilt each pass — byte-identical to what the AC-2 replay reconstructs, so every placement is provably forced and every advanced elimination reads the reduced set (cascades work). Monotonic → terminates.
- Cheapest-first, one productive step per pass (from P-1) → `HardestTechnique` reflects the genuinely-required tier; floor/ceiling brackets meaningful.
- `internal/api` left untouched — no api test asserts `hardestTechnique`/`grade` on `SolveResponse` (allow-list rule).
